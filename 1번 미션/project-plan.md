## 2. 문제 정의와 프로젝트 기획

### 2-1. 문제 한 문장 (팀 결정, 2026-11-26)

> **AMR·로봇 작업구역에서 일하는 고객사 현장 작업자**가 **로봇 이상·고장을 발견했을 때** 무엇을 먼저 해야 하는지 몰라 매뉴얼을 찾느라 대응이 늦어지거나 임의로 접근하는 **불편(위험)**을 **근거가 표시되는 안전수칙 Q&A와 상황별 행동 체크리스트**로 줄이는 웹앱

### 2-2. 문제의 근거 유형

| 근거 유형 | 상태 | 내용 |
|---|---|---|
| 자료 | 있음 | 안전보건규칙 제222~224조 [L1], KOSHA GUIDE G-135-2021 [L2], 회사 AMR 이상 상태 모니터링 기능 [S4] |
| 관찰 | **없음 (확인 필요)** | 고객사 현장 관찰 기회 요청 필요 |
| 인터뷰 | **없음 (확인 필요)** | 케이로드로보틱스 멘토/시운전 엔지니어 인터뷰 필요. 질문 예: "현장에서 이상 시 가장 자주 받는 질문은?", "작업자용 안전수칙 문서가 있는가?" |

→ 현재 문제 정의는 **자료 기반 가설** 단계입니다.

### 2-3. 핵심 기능 (처음 버전, 2개)

1. **근거 있는 Q&A**: 작업자가 질문을 입력하면, 등록된 안전수칙 문서에서 찾은 답변 + 근거(법 조문 번호, 수칙 번호, 문서명)를 함께 보여줌. 근거가 없으면 "등록된 수칙에 없음, 관리자에게 문의"로 답하고 추측하지 않음.
2. **상황별 행동 체크리스트**: 설비 종류(AMR/AGV, 용접로봇 셀 등)와 이상 상황(멈춤, 경고음·경광등, 경로 이탈, 충돌·접촉, 연기·냄새 등)을 고르면 ① 즉시 할 일 ② 하면 안 되는 일 ③ 누구에게 보고 를 순서대로 보여줌.

제외(나중에): 이상 보고서 자동 작성, 음성 입력, 다국어.

### 2-4. 화면 설명

**입력 화면**
- 상단: 설비 종류 선택 버튼 (AMR/AGV · 로봇 셀 · 잘 모르겠음)
- 중간: 자주 묻는 상황 버튼 (예: "AMR이 통로에서 멈췄어요", "로봇에서 경고음이 나요")
- 하단: 자유 질문 입력창 + [질문하기] 버튼
- 화면 맨 아래 고정: "긴급 시 비상정지 버튼을 누르고 관리자에게 연락" 안내 (연락처는 고객사별 설정, **확인 필요**)

**결과 화면**
- 1단: 한 줄 결론 (예: "접근하지 말고 비상정지 후 관리자에게 보고하세요")
- 2단: 행동 체크리스트 — 즉시 할 일 / 하면 안 되는 일 / 보고 대상 (체크박스)
- 3단: 근거 카드 — 출처 문서명, 조문·수칙 번호, 자료 날짜, 원문 링크
- 4단: 신뢰 표시 배지 — "법령 근거" / "기업 수칙 근거" / "샘플 데이터(실습용)"
- 하단: [관련 질문 더보기] [처음으로]

4. 챗봇 답변에 회사 자료를 인용해도 되는 범위

### 3-4. 샘플 데이터 (실습용, 실제 기업 데이터 아님)

Q&A 지식베이스 레코드 형식:

| id | 설비 | 상황 | 질문 | 답변 요약 | 근거 | 데이터 구분 |
|---|---|---|---|---|---|---|
| QA-001 | 로봇 셀 | 이상 발견 | 로봇이 이상하게 움직여요. 어떻게 하죠? | 즉시 운전 정지 조치(비상정지) 후 관리자에게 보고. 임의 재가동 금지 | L1 제222조 제2호 (법령은 사업주 의무 조항) | 법령 근거 + **샘플 데이터** |
| QA-002 | 로봇 셀 | 수리·점검 | 멈춘 로봇을 고치러 들어가도 되나요? | 운전 정지 + 기동스위치 잠금(열쇠 별도 관리) 또는 '작업 중' 표지 부착 후 작업 | L1 제224조 | 법령 근거 + **샘플 데이터** |
| QA-003 | 로봇 셀 | 울타리 | 울타리 문이 열려 있는데 로봇이 움직여요 | 접근 금지, 비상정지, 관리자 보고 | L1 제223조 (울타리 1.8m) | 법령 근거 + **샘플 데이터** |
| QA-004 | AMR/AGV | 멈춤 | AMR이 통로 한가운데 멈춰서 경고음이 나요 | 정면·적재물 아래로 들어가지 말 것, 관리자/관제에 보고 | **가설** (회사 수칙 확인 필요) | **샘플 데이터** |
| QA-005 | AMR/AGV | 비상정지 | AMR 비상정지는 어떻게 하나요? | 차체 비상정지 버튼 또는 관제(원격) 정지 | L2 2.2~2.3항(수동 차단 스위치·원격 정지), 버튼 위치는 **확인 필요** | **샘플 데이터** |

상황별 체크리스트 예시 (**샘플 데이터**): "AMR이 작업 중 멈춤"
- 즉시 할 일: ① 진행 경로·적재물에서 떨어지기 ② 주변 사람에게 알리기 ③ 관리자·관제실에 보고
- 하면 안 되는 일: 직접 밀거나 리셋하기, 적재물 아래로 들어가기, 임의 재가동
- 보고 대상: 라인 관리자 (연락처 **확인 필요**)

### 3-5. 주의 사항

- 챗봇 답변은 현장 안전교육·관리자 지시를 대신하지 않는다고 화면에 명시.
- 법령 조문은 '사업주 의무'로 쓰여 있으므로, 작업자용 문장으로 바꿀 때 원문 링크를 함께 보여줌.
- 회사 수칙을 받기 전까지 AMR 관련 답변은 모두 '가설/샘플'로 표시.
